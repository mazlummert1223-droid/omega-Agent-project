description: Live web behavior of the Agent model and the transparent animated Omega mark used in the UI.

OMEGA AGENT performs live public web retrieval before its parallel specialist calls and passes the resulting context to Researcher, Engineer, Strategist, and Synthesis. The UI should expose that as a real “Canlı İnternet” step.

The Ω brand mark is rendered as a transparent inline SVG in the app UI instead of the photographic source image, which prevents a visible rectangular background. Waiting indicators use the same mark with a restrained amber ring animation rather than generic three-dot typing indicators.

**Why:** The Agent must visibly and functionally use current web context, while the original logo image introduced a square box and generic typing dots weakened brand continuity.

**How to apply:** Preserve the live search step before agent calls, and reuse the transparent Ω glyph for avatars, hero branding, and loading states with reduced-motion support.
