## 📦 KURULUM

### Replit'te Kurulum:

1. **Replit'te yeni bir Python projesi oluştur**

2. **Dosyaları yükle:**
   - `omega_agent.py` → Ana kod
   - `requirements.txt` → Bağımlılıklar

3. **Bağımlılıkları yükle:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Çalıştır:**
   ```bash
   python omega_agent.py
   ```

## 🎮 KULLANIM

### Temel Komutlar:

| Komut | Açıklama |
|-------|----------|
| `ara [konu]` | İnternette araştırma yap |
| `kod yaz [açıklama]` | Kod üret |
| `resim [açıklama]` | Görsel oluştur |
| `web sitesi yap` | Multi-agent proje başlat |
| `çalıştır` | Son kodu çalıştır |
| `durum` | Durum bilgisi göster |
| `çık` | Programdan çık |

### Örnekler:

```
👤 Sen: ara python nedir
🤖 Omega: [Python hakkında detaylı araştırma sonuçları]

👤 Sen: kod yaz hesap makinesi
🤖 Omega: [Python hesap makinesi kodu]

👤 Sen: resim kedi
🤖 Omega: [Kedi görseli oluşturuldu]

👤 Sen: web sitesi yap
🤖 Omega: [4 agent paralel çalışıyor...]
```

## 🧠 MULTI-AGENT SİSTEMİ

"Web sitesi yap" dediğinde Omega kendini 4 parçaya böler:

1. **🔍 Researcher** - Web tasarım trendlerini araştırır
2. **🎨 Designer** - HTML/CSS oluşturur  
3. **💻 Coder** - Backend kodu yazar
4. **🖼️ ImageAgent** - Görsel oluşturur

Hepsi paralel çalışır ve sonunda birleştirir!
