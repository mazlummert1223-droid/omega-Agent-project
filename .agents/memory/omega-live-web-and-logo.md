OMEGA AGENT performs live public web retrieval before its parallel specialist calls and passes the resulting context to Researcher, Engineer, Strategist, and Synthesis. The UI should expose that as a real “Canlı İnternet” step.

The Ω brand mark uses the provided logo artwork as the single source across the app. Its dark surrounding pixels are made transparent without redrawing or reshaping the mark, so the original circular Ω and squared terminals remain intact. Waiting indicators reuse the same artwork with a restrained amber ring animation rather than generic three-dot typing indicators.

**Why:** The Agent must visibly and functionally use current web context, while a hand-drawn replacement changed the logo’s identity and generic typing dots weakened brand continuity.

**How to apply:** Preserve the live search step before agent calls, and reuse the provided Ω artwork for avatars, hero branding, PWA icons, and loading states with reduced-motion support. Animate the surrounding light, not the logo geometry.
